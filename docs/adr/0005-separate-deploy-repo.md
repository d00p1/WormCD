# ADR-0005: Отдельный deploy-репозиторий

**Статус:** accepted
**Дата:** 2026-10-25

## Контекст

Манифесты можно держать в репозитории приложения или отдельно. Важны права CI, аудит деплоев и отсутствие зацикливания CI.

## Решение

Манифесты (compose, overlay, `wormcd.yaml`) живут в отдельном deploy-репозитории. CI приложения имеет право писать только туда, обновляя digest образа.

## Следствия

- Разделение прав: код и деплой-история не смешиваются.
- Push в deploy-репо не триггерит сборку приложения.
- Нужен второй репозиторий и доступ к нему у CI.
- Изменение приложения и его деплой — два коммита в двух репозиториях (атомарности между ними нет).

## Альтернативы

- **Манифесты в репозитории приложения**: проще для соло-разработки, но требует path-фильтров и смешивает права.
- **Любой репозиторий на выбор**: гибко, но без ясного дефолта.
