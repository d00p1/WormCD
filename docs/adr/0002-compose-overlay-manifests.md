# ADR-0002: Compose + overlay как формат манифестов

**Статус:** accepted
**Дата:** 2026-10-25

## Контекст

Пользователи Swarm уже описывают приложения в compose/stack YAML. Собственный формат дал бы полный контроль, но потребовал бы своего языка, валидации, тулинга и обучения.

## Решение

Базовое описание приложения — `compose.yaml`. Окружение описывается обычным compose override-файлом с семантикой `docker compose -f base -f overlay`. CD-политики (targets, cluster, syncPolicy) живут отдельно в `wormcd.yaml`.

## Следствия

- Совместимость с существующими compose-файлами и локальной проверкой через `docker compose config`.
- Ограничены возможности Compose, которые не поддерживает Swarm; неподдерживаемое отклоняется с явной ошибкой.
- `wormcd.yaml` — единственный файл собственного формата.
- Слияние только merge-семантикой, без `!reset`/`!override` в v0.

## Альтернативы

- **Собственный spec в духе CRD**: больше контроля, но свой язык и тулинг с нуля.
- **Оба формата**: максимум гибкости, максимум работы.
