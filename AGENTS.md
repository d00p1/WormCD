# WormCD

## Quality gates

Run `mise run check` before a change is done. CI runs the same command.
`mise run fix` applies safe autofixes; review the diff afterwards.

`internal/manifest/testdata/basic/desired.golden.json` is generated by
`go test ./internal/manifest -run TestGoldenBasic -update`. Never edit it by
hand. `bin/wormcd` is build output and is not committed.

Never disable a lint rule or add a suppression to get a change through. An
exception must name one path and one rule, carry a reason and a review date,
and needs a human decision.
