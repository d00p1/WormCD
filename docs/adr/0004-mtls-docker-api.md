# ADR-0004: Доступ к удалённым кластерам по mTLS

**Статус:** accepted
**Дата:** 2026-10-25

## Контекст

Один control plane управляет N Swarm-кластерами и должен выполнять Docker API-вызовы в каждом из них. Варианты: публиковать Docker API, ходить через SSH или ставить агент.

## Решение

Удалённые кластеры доступны по Docker API на 2376 с mTLS: отдельный CA и клиентский сертификат на кластер. Управляющий кластер, в котором живёт control plane, подключается через локальный `unix:///var/run/docker.sock`. Сетевой доступ ограничивается ACL/VPN.

## Следствия

- Docker API — root-эквивалент; компенсируется сетевыми политиками и authorization-плагином Swarm, а не логикой WormCD.
- Ротация сертификатов и хранение ключей становятся эксплуатационной задачей.
- Кластеры без входящего доступа не поддерживаются до появления agent mode (M5).
- Нет дополнительного компонента в v0.

## Альтернативы

- **SSH-туннель**: API не публикуется, но хрупко и завязано на SSH-ключи.
- **Агент сразу**: безопаснее и работает offline, но +1 компонент в v0.
